拼图生成器

将图片切分为拼图块的 Python 工具，支持多种切分布局和导出格式

项目简介

🧩

核心功能

  • 多种切分密度（3x3 到 8x8）
  • 两种拼图形状（经典/直线）
  • Web 界面，响应式设计
  • 导出 PNG / HTML / SVG
